本机访问：
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ $fullName }}-frontend 8080:{{ .Values.frontend.service.port }}
  然后打开 http://127.0.0.1:8080

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "opencgp.backendHost" . }} {{ .Values.api.service.port }}:{{ .Values.api.service.port }}
  curl -s http://127.0.0.1:{{ .Values.api.service.port }}/health
  curl -s http://127.0.0.1:{{ .Values.api.service.port }}/metrics | head

读取自动生成的敏感配置：

重要提示：
  database backend = {{ .Values.config.databaseBackend }}，queue backend = {{ .Values.config.queueBackend }}，storage backend = {{ .Values.config.storageBackend }}，executor = {{ .Values.config.executorBackend }}。
{{- if eq .Values.mode "ha" }}
  HA 模式下所有 API/Worker 实例共用同一个 Redis DB；不要把不同实例指向不同库编号，否则任务会被错误的实例抢走。
  API 节点 JOB_CONCURRENCY=0 只处理 HTTP，任务全部由 worker-deployment 消费（replicas={{ .Values.worker.replicas }}）。
{{- else }}
  单机模式下 backend.replicas 必须为 1（内置 PG/Redis/rustfs 与 PVC 均为单副本）；需要多副本请使用 mode=ha + 外部依赖。
{{- end }}
  /metrics 只经 Pod 注解被 Prometheus 抓取，不通过 Ingress 暴露。
